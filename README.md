aodocs-kb-search-enter
======================

On the [AODocs Support website], pressing Enter in the search field always
opens the search results page. This user script moves that function to
Option-Enter, and when Enter is pressed, redirects to the article selected in
the search field suggestion list.


[AODocs Support website]: https://support.aodocs.com/hc/en-us


## Install
Open the [raw script][1] and click “Install” in the resulting dialog. A [more
detailed explanation][2] is available on the Greasemonkey wiki.
